# אופק דסק — הדגמה פומבית

אתר הדגמה להצגה ולתיק עבודות. אותו מבנה מסכים ואותו שימוש בדפי הדמו: דף הבית, מודולים, מערכות בפעולה ויועץ שיווק.

הדגמה לתיק עבודות. כל הזכויות שמורות ל-OfficeSense ול-Business Room. השמות, הנתונים והמסכים מומצאים, בלי פרטים מזהים ובלי מידע סודי.

השמות, העסקים, הציטוטים, המספרים והמסכים מומצאים. אין באתר פרטים מזהים של לקוחות, ואין מידע סודי או רגיש.

בדמו הזה אין מפתחות, אין שרת, אין שליחת מייל ואין סליקת תשלום. טפסים מציגים תוצאה על המסך ונשארים בדפדפן.

## הרצה

כל קובץ הוא סטטי. אפשר לפתוח עם שרת מקומי:

```bash
npx serve .
```

אחר כך לפתוח את הכתובת שמופיעה בטרמינל. דף הבית טוען את `content.json`, לכן פתיחה ישירה של הקובץ מהדיסק לא תציג את כל הטקסטים.
